# 🖋️ A Forja do Cronista: Laboratório de Narrativas

> *"O código constrói a lógica, mas a história constrói a alma."*

Bem-vindo ao repositório central das minhas construções literárias. Este não é apenas um arquivo de textos; é um **"Segundo Cérebro"** estruturado para Worldbuilding, desenvolvimento de personagens e escrita de ficção histórica e fantástica.

Aqui, a Engenharia de Software encontra o **Realismo Poético Brutal**.

---

## 🏗️ Sobre o Repositório

Este repositório serve como *backend* criativo para meus projetos de escrita. Ele é projetado para ser consumido nativamente pelo **[Obsidian.md](https://obsidian.md/)**, utilizando a poder dos *wikilinks* (`[[...]]`) para criar uma rede neural de eventos, personagens e temas.

### 📜 O Manifesto do Cronista
Toda história aqui segue os pilares da minha filosofia de escrita:
1.  **Vocação:** Contar a verdade expondo a beleza quebrada e a redenção.
2.  **Estilo:** **Realismo Poético Brutal**.
    * *Textura:* O mundo tem cheiro, peso e sujeira.
    * *Perspectiva:* Nada é neutro; tudo é filtrado pela dor ou esperança do personagem.
    * *Redenção:* A fé cristã não é um adorno, é a fundação que contrasta com a escuridão do mundo.

## 🛠️ Como Navegar (Stack Tecnológico)

Para a melhor experiência (ver as conexões e o Graph View):
1.  Clone este repositório.
2.  Abra a pasta raiz como um **Cofre (Vault)** no [Obsidian](https://obsidian.md/).
3.  Instale o plugin **Excalidraw** (opcional) para visualizar diagramas complexos se houver.
4.  Use `Ctrl+Click` nos links para navegar entre a teologia, a história e a narrativa.

## 🤖 Declaração de Uso de IA e Ética Criativa

Este projeto adota uma postura transparente sobre o uso de tecnologias de Inteligência Artificial Generativa:

* **Ferramenta, não Autor:** A IA foi utilizada estritamente como ferramenta de suporte mecânico (pesquisa histórica rápida, estruturação de pastas, brainstorm de sinônimos e organização de ideias).
* **100% Autoria Humana:** O arco narrativo, a prosa literária, os diálogos e as decisões teológicas/dramáticas são fruto exclusivo da criatividade e do trabalho manual do autor.
* **Visualização Conceitual:** As imagens presentes neste repositório (concept art) foram geradas por IA apenas para auxiliar na visualização de cenários e atmosfera durante o processo de escrita. A versão comercial/final da obra utilizará artes comissionadas de ilustradores humanos.
